# Security Policy

## Supported versions

Only the latest release receives security fixes.

| Version       | Supported |
| ------------- | --------- |
| v0.x (latest) | Yes       |

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, pull
requests or discussions.

Report them privately through GitHub instead:
[open a private vulnerability report](https://github.com/mattoddie/go-ukdays/security/advisories/new).

Include as much of the following as you can:

- a description of the issue and its impact
- the version affected
- a minimal program or command that reproduces it

You should get an acknowledgement within 7 days. Once the issue is confirmed,
a fix will be released and a GitHub security advisory published, crediting you
unless you ask otherwise.
